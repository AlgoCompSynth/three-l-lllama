1. Install Alpine on your Raspberry Pi. You will need at least a
Pi 4 and at least 4 GB of RAM. Even with that much capacity what
you can do with AI models will be limited.

    During the setup, make sure you have enabled the "community"
    repository option, that your shell is `bash` and not the
    Alpine default, and that `git` is installed.

2. Clone this repository and run `./set-up-hosting.sh`. That should
do it.
