## A toolbox for local inference

`three-l-llama` is a `llama.cpp`-based toolbox container inspired by <https://github.com/ggml-org/llama.cpp/blob/master/docs/backend/CUDA-FEDORA.md>. I've ported it to Raspberry Pi OS for the Raspberry Pi 5 and added code so it can detect whether it's on a Pi or on a Linux host, and, if on Linux, whether there's a GPU or not.
